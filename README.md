# YourChoice PLUS

Sistema de Gestión de Streaming desarrollado en Go.

## Objetivo

Permitir a los usuarios crear planes personalizados de streaming seleccionando series de diferentes categorías.

## Funcionalidades

- Mostrar catálogo de series.
- Selección de contenido.
- Clasificación según popularidad.
- Cálculo automático de precios.
- Límite máximo de $200 por plan.

## Tecnologías

- Go
- Paquete fmt
- Programación funcional
